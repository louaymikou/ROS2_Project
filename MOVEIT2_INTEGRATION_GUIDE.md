## 🎯 WHY INTEGRATE MOVEIT2?

### Current Limitations (Without MoveIt2)

**Your current arm control:**
```python
# Manual joint control - you specify each joint angle
traj.joint_names = ['shoulder_joint', 'elbow_joint', 'gripper_rotate_joint']
point.positions = [0.5, -0.8, 0.0]  # Must calculate these manually!
```

**Problems:**
- ❌ No inverse kinematics (can't say "move end-effector to position X,Y,Z")
- ❌ No collision avoidance (arm might hit robot body or obstacles)
- ❌ No path planning (just linear interpolation between positions)
- ❌ No pick-and-place primitives
- ❌ Manual calculation of joint angles (complex math)
- ❌ No visualization of planned motion

### With MoveIt2

**Advanced arm control:**
```python
# Cartesian space control - specify where you want the gripper
move_group.set_pose_target([x=0.5, y=0.0, z=0.3])
move_group.plan_and_execute()  # MoveIt handles everything!
```

**Benefits:**
- ✅ **Inverse Kinematics (IK):** Specify gripper position, MoveIt calculates joint angles
- ✅ **Collision Avoidance:** Arm won't collide with robot body or environment
- ✅ **Motion Planning (OMPL):** Smooth, optimized trajectories
- ✅ **Pick & Place:** Built-in primitives for grasping objects
- ✅ **Cartesian Planning:** Move in straight lines in 3D space
- ✅ **Visual Planning:** Interactive motion planning in RViz
- ✅ **Named Poses:** Predefined positions (home, ready, tucked)

### Step 2: Prepare Robot URDF (15 minutes)

**CRITICAL:** Your URDF must have proper collision geometry for MoveIt to work.

**Check your `description/robot.urdf.xacro`:**

```xml
<!-- Each link MUST have <collision> elements -->
<link name="arm_1_link">
  <!-- Visual (what you see) -->
  <visual>
    <origin xyz="-0.3 0 0.3" rpy="0 0 0"/>
    <geometry>
      <box size="0.15 0.15 0.6"/>
    </geometry>
    <material name="arm_orange"/>
  </visual>
  
  <!-- Collision (what MoveIt uses for planning) -->
  <collision>
    <origin xyz="-0.3 0 0.3" rpy="0 0 0"/>
    <geometry>
      <box size="0.15 0.15 0.6"/>  <!-- Should match visual or be simplified -->
    </geometry>
  </collision>
  
  <!-- Inertial (for physics) -->
  <inertial>
    <mass value="0.1"/>
    <origin xyz="-0.3 0 0.3" rpy="0 0 0"/>
    <inertia ixx="0.001" ixy="0" ixz="0" iyy="0.001" iyz="0" izz="0.001"/>
  </inertial>
</link>
```

- `gripper_base_link` ✓

**If missing, add collision geometry to each link.**

### File 2: `config/kinematics.yaml`

**Location:** `src/my_robot_moveit_config/config/kinematics.yaml`

```yaml
arm:
  kinematics_solver: kdl_kinematics_plugin/KDLKinematicsPlugin
  kinematics_solver_search_resolution: 0.005
  kinematics_solver_timeout: 0.05
  kinematics_solver_attempts: 3

# Gripper doesn't need IK solver
```

**Parameters explained:**
- `search_resolution`: Step size for IK search (smaller = more accurate, slower)
- `timeout`: Max time to find IK solution (seconds)
- `attempts`: Number of random seeds to try

**Alternative solvers:**
- `kdl_kinematics_plugin/KDLKinematicsPlugin` - Simple, fast (good for 2-3 DOF arms)
- `trac_ik_kinematics_plugin/TRAC_IKKinematicsPlugin` - More robust (better for 6+ DOF)
- `srv_kinematics_plugin/SrvKinematicsPlugin` - Analytical (very fast if available)

For your 3-DOF arm, KDL is perfect.

    type: geometric::RRTstar
    range: 0.0

## 🚀 LAUNCH FILES

### Launch File 1: Integrated Simulation with MoveIt

**Create:** `src/my_robot_controller/launch/launch_sim_with_moveit.launch.py`

```python
#!/usr/bin/env python3
import os
from ament_index_python.packages import get_package_share_directory
from launch import LaunchDescription
from launch.actions import IncludeLaunchDescription, DeclareLaunchArgument, TimerAction
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node

def generate_launch_description():
    # Get package directories
    robot_pkg = get_package_share_directory('my_robot_controller')
    moveit_pkg = get_package_share_directory('my_robot_moveit_config')
    
    # Launch arguments
    use_sim_time = LaunchConfiguration('use_sim_time', default='true')
    
    # 1. Launch Gazebo simulation with robot
    gazebo_simulation = IncludeLaunchDescription(
        PythonLaunchDescriptionSource([
            os.path.join(robot_pkg, 'launch', 'launch_sim.launch.py')
        ])
    )
    
    # 2. Launch MoveIt move_group node
    # Add delay to ensure controllers are loaded first
    move_group_launch = TimerAction(
        period=5.0,  # Wait 5 seconds for controllers to be ready
        actions=[
            IncludeLaunchDescription(
                PythonLaunchDescriptionSource([
                    os.path.join(moveit_pkg, 'launch', 'move_group.launch.py')
                ]),
                launch_arguments={
                    'use_sim_time': use_sim_time,
                    'publish_monitored_planning_scene': 'true'
                }.items()
            )
        ]
    )
    
    # 3. Launch RViz with MoveIt plugin
    rviz_config = os.path.join(moveit_pkg, 'config', 'moveit.rviz')
    rviz_node = TimerAction(
        period=7.0,  # Wait for move_group to be ready
        actions=[
            Node(
                package='rviz2',
                executable='rviz2',
                name='rviz2_moveit',
                output='screen',
                arguments=['-d', rviz_config],
                parameters=[
                    {'use_sim_time': use_sim_time}
                ]
            )
        ]
    )
    
    return LaunchDescription([
        DeclareLaunchArgument(
            'use_sim_time',
            default_value='true',
            description='Use simulation time'
        ),
        gazebo_simulation,
        move_group_launch,
        rviz_node
    ])
```

**Make executable:**
```bash
chmod +x src/my_robot_controller/launch/launch_sim_with_moveit.launch.py
```

from rclpy.action import ActionClient
from moveit_msgs.action import MoveGroup
from geometry_msgs.msg import Pose, PoseStamped
from moveit_msgs.msg import Constraints, PositionConstraint, OrientationConstraint
from shape_msgs.msg import SolidPrimitive
from std_msgs.msg import Header
import time

class MoveItArmController(Node):
    def __init__(self):
        super().__init__('moveit_arm_controller')
        
        # Action client for move_group
        self._action_client = ActionClient(
            self, 
            MoveGroup, 
            '/move_action'
        )
        
        self.get_logger().info("Waiting for MoveIt action server...")
        self._action_client.wait_for_server()
        self.get_logger().info("MoveIt action server connected!")
        
    def move_to_named_target(self, target_name):
        """
        Move to a predefined pose (home, ready, tucked, etc.)
        
        Args:
            target_name (str): Name of the target pose
        """
        goal = MoveGroup.Goal()
        goal.request.group_name = "arm"
        goal.request.num_planning_attempts = 10
        goal.request.allowed_planning_time = 5.0
        goal.request.max_velocity_scaling_factor = 0.1
        goal.request.max_acceleration_scaling_factor = 0.1
        
        # Set named target
        goal.request.goal_constraints.append(
            self._create_named_constraint(target_name)
        )
        
        self.get_logger().info(f"Moving to named target: {target_name}")
        future = self._action_client.send_goal_async(goal)
        rclpy.spin_until_future_complete(self, future)
        
        result = future.result()
        if result.accepted:
            self.get_logger().info("Goal accepted!")
            result_future = result.get_result_async()
            rclpy.spin_until_future_complete(self, result_future)
            self.get_logger().info("Motion complete!")
        else:
            self.get_logger().error("Goal rejected!")
            
    def move_to_pose(self, x, y, z, roll=0.0, pitch=0.0, yaw=0.0):
        """
        Move end-effector to Cartesian position.
        
        Args:
            x, y, z: Position in meters (relative to base_link)
            roll, pitch, yaw: Orientation in radians
        """
        goal = MoveGroup.Goal()
        goal.request.group_name = "arm"
        goal.request.num_planning_attempts = 10
        goal.request.allowed_planning_time = 5.0
        goal.request.max_velocity_scaling_factor = 0.2
        goal.request.max_acceleration_scaling_factor = 0.2
        
        # Create pose goal
        pose = PoseStamped()
        pose.header = Header()
        pose.header.frame_id = "base_link"
        pose.pose.position.x = x
        pose.pose.position.y = y
        pose.pose.position.z = z
        
        # Convert euler to quaternion
        from scipy.spatial.transform import Rotation
        r = Rotation.from_euler('xyz', [roll, pitch, yaw])
        quat = r.as_quat()
        
        pose.pose.orientation.x = quat[0]
        pose.pose.orientation.y = quat[1]
        pose.pose.orientation.z = quat[2]
        pose.pose.orientation.w = quat[3]
        
        # Add position constraint
        goal.request.goal_constraints.append(
            self._create_pose_constraint(pose)
        )
        
        self.get_logger().info(f"Planning to pose: x={x}, y={y}, z={z}")
        future = self._action_client.send_goal_async(goal)
        rclpy.spin_until_future_complete(self, future)
        
        result = future.result()
        if result.accepted:
            self.get_logger().info("Executing trajectory...")
            result_future = result.get_result_async()
            rclpy.spin_until_future_complete(self, result_future)
            self.get_logger().info("Motion complete!")
        else:
            self.get_logger().error("Planning failed!")
    
    def _create_named_constraint(self, target_name):
        """Helper to create named target constraint"""
        constraint = Constraints()
        constraint.name = target_name
        return constraint
    
    def _create_pose_constraint(self, pose_stamped):
        """Helper to create pose constraint"""
        constraint = Constraints()
        
        # Position constraint
        pos_constraint = PositionConstraint()
        pos_constraint.header = pose_stamped.header
        pos_constraint.link_name = "gripper_base_link"
        
        # Define tolerance region (box around target)
        primitive = SolidPrimitive()
        primitive.type = SolidPrimitive.SPHERE
        primitive.dimensions = [0.01]  # 1cm tolerance
        
        pos_constraint.constraint_region.primitives = [primitive]
        pos_constraint.constraint_region.primitive_poses = [pose_stamped.pose]
        pos_constraint.weight = 1.0
        
        constraint.position_constraints = [pos_constraint]
        
        # Orientation constraint
        orient_constraint = OrientationConstraint()
        orient_constraint.header = pose_stamped.header
        orient_constraint.link_name = "gripper_base_link"
        orient_constraint.orientation = pose_stamped.pose.orientation
        orient_constraint.absolute_x_axis_tolerance = 0.1
        orient_constraint.absolute_y_axis_tolerance = 0.1
        orient_constraint.absolute_z_axis_tolerance = 0.1
        orient_constraint.weight = 1.0
        
        constraint.orientation_constraints = [orient_constraint]
        
        return constraint


def main(args=None):
    rclpy.init(args=args)
    controller = MoveItArmController()
    
    try:
        # Example usage
        time.sleep(2)  # Wait for everything to initialize
        
        # Move to home position
        controller.get_logger().info("=== Moving to HOME ===")
        controller.move_to_named_target("home")
        time.sleep(2)
        
        # Move to ready position
        controller.get_logger().info("=== Moving to READY ===")
        controller.move_to_named_target("ready")
        time.sleep(2)
        
        # Move to Cartesian position
        controller.get_logger().info("=== Moving to CARTESIAN POSE ===")
        controller.move_to_pose(
            x=0.5,   # 50cm forward
            y=0.0,   # centered
            z=0.3,   # 30cm up
            roll=0.0,
            pitch=0.0,
            yaw=0.0
        )
        time.sleep(2)
        
        # Return home
        controller.get_logger().info("=== Returning HOME ===")
        controller.move_to_named_target("home")
        
        controller.get_logger().info("=== Demo complete! ===")
        
    except KeyboardInterrupt:
        pass
    finally:
        controller.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

#!/usr/bin/env python3
"""
Simple gripper control using MoveIt2.
"""

import rclpy
from rclpy.node import Node
from rclpy.action import ActionClient
from control_msgs.action import FollowJointTrajectory
from trajectory_msgs.msg import JointTrajectory, JointTrajectoryPoint
from builtin_interfaces.msg import Duration

class GripperController(Node):
    def __init__(self):
        super().__init__('gripper_controller')
        
        self._action_client = ActionClient(
            self,
            FollowJointTrajectory,
            '/gripper_controller/follow_joint_trajectory'
        )
        
        self.get_logger().info("Waiting for gripper controller...")
        self._action_client.wait_for_server()
        self.get_logger().info("Gripper controller ready!")
    
    def open_gripper(self):
        """Open gripper fully"""
        self._move_gripper([0.04, -0.04])
        
    def close_gripper(self):
        """Close gripper fully"""
        self._move_gripper([0.0, 0.0])
        
    def set_gripper(self, width):
        """Set gripper to specific width (0.0 to 0.08m)"""
        half_width = width / 2.0
        self._move_gripper([half_width, -half_width])
        
    def _move_gripper(self, positions):
        """Internal method to move gripper"""
        goal = FollowJointTrajectory.Goal()
        
        # Create trajectory
        traj = JointTrajectory()
        traj.joint_names = ['gripper_left_joint', 'gripper_right_joint']
        
        point = JointTrajectoryPoint()
        point.positions = positions
        point.time_from_start = Duration(sec=1, nanosec=0)
        
        traj.points = [point]
        goal.trajectory = traj
        
        # Send goal
        self.get_logger().info(f"Moving gripper to: {positions}")
        future = self._action_client.send_goal_async(goal)
        rclpy.spin_until_future_complete(self, future)
        
        result = future.result()
        if result.accepted:
            result_future = result.get_result_async()
            rclpy.spin_until_future_complete(self, result_future)
            self.get_logger().info("Gripper motion complete!")


def main():
    rclpy.init()
    gripper = GripperController()
    
    import time
    
    # Demo
    gripper.open_gripper()
    time.sleep(2)
    
    gripper.close_gripper()
    time.sleep(2)
    
    gripper.open_gripper()
    
    gripper.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

    def navigate_to(self, x, y, yaw=0.0):
        """Navigate base to position"""
        self.get_logger().info(f"Navigating to x={x}, y={y}")
        
        goal = NavigateToPose.Goal()
        goal.pose.header.frame_id = "map"
        goal.pose.pose.position.x = x
        goal.pose.pose.position.y = y
        goal.pose.pose.position.z = 0.0
        
        # Convert yaw to quaternion
        from scipy.spatial.transform import Rotation
        r = Rotation.from_euler('z', yaw)
        quat = r.as_quat()
        goal.pose.pose.orientation.x = quat[0]
        goal.pose.pose.orientation.y = quat[1]
        goal.pose.pose.orientation.z = quat[2]
        goal.pose.pose.orientation.w = quat[3]
        
        future = self.nav_client.send_goal_async(goal)
        rclpy.spin_until_future_complete(self, future)
        
        result = future.result()
        if result.accepted:
            result_future = result.get_result_async()
            rclpy.spin_until_future_complete(self, result_future)
            self.get_logger().info("Navigation complete!")

        """Execute pick sequence"""
        self.get_logger().info("=== PICK SEQUENCE ===")
        
        # 1. Move arm to ready position
        # (use MoveIt arm control)
        
        # 2. Move to pre-grasp pose
        # (Cartesian planning)
        
        # 3. Open gripper
        # (gripper controller)
        
        # 4. Move to grasp pose
        # (Cartesian planning with constraints)
        
        # 5. Close gripper
        # (gripper controller)
        
        # 6. Lift object
        # (Cartesian planning upward)
        
        # 7. Tuck arm
        pass
        
    def place_object(self):
        """Execute place sequence"""
        self.get_logger().info("=== PLACE SEQUENCE ===")

        # 4. Open gripper

## 🔧 TROUBLESHOOTING

### Problem 1: MoveIt Controllers Not Found

**Symptoms:**
```
[ERROR] Unable to identify any set of controllers that can actuate the specified joints
```

**Solution:**
1. Check controller names match:
   ```bash
   ros2 control list_controllers
   ```
   Should show: `arm_controller` and `gripper_controller`

2. Verify `moveit_controllers.yaml` has correct names
3. Ensure controllers are in `active` state

---

### Problem 2: IK Fails to Find Solution

**Symptoms:**
```
[WARN] IK solver failed to find solution
```

**Solutions:**
- **Target too far:** Move closer to robot workspace
- **Unreachable orientation:** Try different end-effector orientation
- **Joint limits:** Check if target requires joints beyond limits
- **Increase attempts:** In `kinematics.yaml`, increase `kinematics_solver_attempts`

---

### Problem 3: Planning Takes Too Long

**Symptoms:**
- Planning takes >10 seconds
- Often fails to find path

**Solutions:**
```yaml
# In ompl_planning.yaml, increase timeout:
allowed_planning_time: 10.0  # Increase from 5.0

# Or use faster planner:
default_planner_config: RRT  # Instead of RRTstar
```

---

### Problem 4: Collision Between Arm Links

**Symptoms:**
```
[ERROR] Start state appears to be in collision
```

**Solutions:**
1. **Check self-collision matrix:**
   - Run Setup Assistant again
   - Regenerate collision matrix
   - Disable collisions between adjacent links

2. **Verify URDF collision geometry:**
   - Ensure collision meshes are simplified
   - Check for overlapping collision geometry

---

### Problem 5: RViz Crashes or Freezes

**Solutions:**
```bash
# Reduce planning scene update rate
# In move_group.launch.py, add:
parameters=[
  {'planning_scene_monitor.publish_planning_scene': True},
  {'planning_scene_monitor.publish_geometry_updates': True},
  {'planning_scene_monitor.publish_state_updates': True},
  {'planning_scene_monitor.publish_transforms_updates': True},
  {'planning_scene_monitor.publish_planning_scene_hz': 1.0}  # Reduce from 10.0
]
```

## 📊 PERFORMANCE TUNING

### Speed vs Accuracy Trade-offs

**For fast motion (demo, testing):**
```python
goal.request.max_velocity_scaling_factor = 1.0      # 100% speed
goal.request.max_acceleration_scaling_factor = 1.0  # 100% acceleration
goal.request.allowed_planning_time = 1.0            # 1 second timeout
```

**For safe, precise motion (real operations):**
```python
goal.request.max_velocity_scaling_factor = 0.1      # 10% speed
goal.request.max_acceleration_scaling_factor = 0.1  # 10% acceleration
goal.request.allowed_planning_time = 5.0            # 5 second timeout
```

### Planning Algorithm Selection

| Planner | Speed | Optimality | Use Case |
|---------|-------|------------|----------|
| RRT | Fast | Poor | Quick demos, simple obstacles |
| RRTConnect | Very Fast | Good | General use (RECOMMENDED) |
| RRTstar | Slow | Optimal | When path quality matters most |
| PRM | Medium | Good | Static environment, reuse roadmap |
| FMT | Fast | Better than RRT | Good for simple arms |
